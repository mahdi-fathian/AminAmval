==============================================================
 امین اموال ناواکو — نسخهٔ نهایی ویندوز (v1.1.0)
==============================================================

این بسته کاملاً مستقل است؛ برای اجرا «هیچ چیز» نیاز به نصب
ندارد (Node.js همراه بسته است).

--------------------------------------------------------------
 ۱) اجرا
--------------------------------------------------------------
  - روی فایل  start-windows.bat  دوبار کلیک کنید.
  - پنجرهٔ سیاه باز می‌ماند (این یعنی سرور در حال اجراست؛ نبندید).
  - در مرورگر باز کنید:
        http://localhost:8080

  توقف: پنجره را ببندید یا Ctrl+C بزنید.

--------------------------------------------------------------
 ۲) ورود اولیه (فقط این دو حساب ساخته می‌شوند)
--------------------------------------------------------------
  مدیر سامانه   :  admin   /  Admin1289@@@
  جمعدار اموال  :  jamdar  /  Jamdar1289@@@

  * هر دو در اولین ورود باید رمز را تغییر دهند.
  * دیتابیس کاملاً خالی است؛ فقط همین دو حساب اجباری وجود دارند
    (هیچ دسته، واحد، کاربر یا اموال نمونه‌ای نیست).

--------------------------------------------------------------
 ۳) پوشه‌ها و داده‌ها
--------------------------------------------------------------
  wwwroot\        رابط کاربری (وب‌سایت)
  data\           دیتابیس، تصاویر، کلیدها و پشتیبان‌ها (خودکار ساخته می‌شود)
  data\initial-credentials.txt   رمزهای اولیه (پس از تحویل حذف کنید)
  runtime\node.exe             Node.js همراه بسته

--------------------------------------------------------------
 ۴) تنظیمات دلخواه (اختیاری)
--------------------------------------------------------------
  می‌توانید متغیرها را قبل از اجرا در خط فرمان (cmd) تنظیم کنید:

    set PORT=9090
    set ADMIN_PASSWORD=رمز-قوی-جدید
    start-windows.bat

  یا مقادیر را مستقیم داخل start-windows.bat ویرایش کنید.

--------------------------------------------------------------
 ۵) استفادهٔ واقعی در سازمان (چند کاربر همزمان)
--------------------------------------------------------------
  این روش دمو/تک‌کاربری است. برای استفادهٔ واقعی (چند کاربر،
  همیشه‌بالا، پشتیبان‌گیری خودکار) روی یک سرور مستقر کنید:
    - Docker:  docker run -d --restart unless-stopped -p 8080:8080 \
                 -v amin-data:/data ghcr.io/mahdi-fathian/aminamval:latest
    - Render (رایگان):  https://aminamval.onrender.com
  جزئیات کامل در  DEPLOY-PUBLIC.md  آمده است.

--------------------------------------------------------------
 ۶) بازیابی رمز در صورت فراموشی (حالت اضطراری)
--------------------------------------------------------------
  اگر هر دو حساب قفل/فراموش شد، فایل data\ را حذف کنید و
  start-windows.bat را دوباره اجرا کنید تا سامانه با دیتابیس
  خالی و همان دو حساب اولیه از نو ساخته شود.
  (فقط در صورتی که دادهٔ مهمی هنوز ثبت نشده باشد.)
