■ این نسخه کاملاً مستقل است
  - نیازی به نصب Node.js، دات‌نت، SQL Server یا هیچ برنامهٔ دیگری نیست.
  - همه‌چیز (Node.js ویندوز + وابستگی‌ها + رابط کاربری) داخل همین پوشه است.

----------------------------------------------------------------
■ روش اجرا (خیلی ساده)
----------------------------------------------------------------
  1) کل پوشه را از ZIP خارج کنید (Extract All). مهم!
     اگر فایل را داخل خود ZIP باز کنید، برنامه اجرا نمی‌شود.

  2) روی فایل  start-windows.bat  دوبار کلیک کنید.

  3) چند ثانیه صبر کنید؛ یک پنجرهٔ سیاه باز می‌ماند و
     مرورگر خودش باز می‌شود.

  4) آدرس سامانه:   http://127.0.0.1:8080

  5) برای خاموش کردن: پنجرهٔ سیاه را ببندید (یا Ctrl+C).

■ اگر شروع نشد؟ (رفع اشکال)
----------------------------------------------------------------
  1. اگر پنجرهٔ سیاه فقط یک لحظه باز شد و بسته شد:
     - مطمئن شوید پوشه را Extract کرده‌اید (نه اجرا داخل ZIP).
     - فایل  startup-log.txt  که کنار start-windows.bat ساخته
       می‌شود را باز کنید؛ دلیل خطا در آن نوشته شده است.

  2. اگر ویندوز هشدار داد (Windows protected your PC / SmartScreen):
     - روی More info و بعد Run anyway کلیک کنید.
     - یا راست‌کلیک روی فایل ZIP → Properties → تیک
       "Unblock" را بزنید و بعد Extract کنید.

  3. اگر آنتی‌ویروس فایل runtime\node.exe را بلاک کرد:
     - آن را در لیست مجاز (Allow / Exception) قرار دهید.
     - این فایل، نسخهٔ رسمی Node.js 22 است و سالم می‌باشد.

  4. اگر پورت 8080 اشغال بود:
     - برنامه خودش پورت خالی بعدی را انتخاب می‌کند و آدرس
       درست را در همان پنجرهٔ سیاه و در startup-log.txt
       نشان می‌دهد. (مثلاً http://127.0.0.1:8081)

  5. اگر پوشه را در مسیری با حروف فارسی گذاشته‌اید و مشکل شد:
     - پوشه را به مسیر ساده‌تری مثل  C:\AminAmval  منتقل کنید.

  6. دسترسی از رایانه‌های دیگر (شبکهٔ داخلی):
     - فایل start-windows.bat را با Notepad باز کنید و خط
       set "HOST=127.0.0.1"  را به  set "HOST=0.0.0.0"  تغییر دهید،
       سپس در Firewall ویندوز اجازهٔ دسترسی بدهید.
     - از رایانه‌های دیگر آدرس  http://IP-این-رایانه:8080  را باز کنید.

----------------------------------------------------------------
■ پشتیبان‌گیری (Backup)
----------------------------------------------------------------
  - همهٔ داده‌ها در پوشهٔ  data  کنار همین فایل ذخیره می‌شود.
  - برای پشتیبان‌گیری کافی است از پوشهٔ data یک کپی بگیرید.
  - برنامه روزانه یک نسخهٔ پشتیبان خودکار هم در
    data\backups  می‌سازد و ۱۴ روز آخر را نگه می‌دارد.
  - پوشهٔ data را با اطلاعات محرمانه در جای امن نگه دارید.
